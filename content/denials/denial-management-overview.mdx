## Denial vs rejection

- **Rejection** — stopped before adjudication
- **Denial** — adjudicated with a reason code and typically $0 payment (or non-covered determination)

## Work pattern

1. Read CARC/RARC (or payer remark) on each line
2. Classify: eligibility, COB, auth, coding, enrollment, duplicate, TFL, medical necessity, bundling, etc.
3. Check client SOP for **callable vs non-callable**
4. Research portal first
5. Act: correct/resubmit, appeal, task specialty team, bill other payer, or patient transfer

## Callable vs non-callable (typical)

| Often callable | Often non-callable (route first) |
| --- | --- |
| No response / not on file | Coding / bundling / NCCI |
| COB order unclear | Clear duplicate with original found |
| Underpayment disputes | Some medical necessity needing coder/clinician |
| Auth retro possibility | Provider enrollment (credentialing owns) |

Always override with **your client update**.
