## When this applies

Modifier does not match CPT rules — coding review required.

## Call / portal questions

1. Which CPT and modifier combination denied?
2. What remark code was returned?
3. Is a corrected claim or appeal required?
4. May I have claim# and call ref#?

## Research checklist

- Task coding with exact codes and remarks
- Resubmit corrected claim after coding update

## Typical actions

- Tasked coding team
- Need coding assistance
- Resubmitted the claim
- Need to submit an appeal
- Need client assistance

## Notes

Always follow your client SOP. Remark codes can change the true root cause — open the matching scenario if the payer explanation differs from the denial title.
