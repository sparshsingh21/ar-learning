## When this applies

Referring/ordering provider enrollment issue — credentialing path.

## Call / portal questions

1. Which referring NPI is on the claim?
2. What is the enrollment status on DOS?
3. Can claims reprocess after enrollment update?
4. May I have claim# and call ref#?

## Research checklist

- Task credentialing with payer statements
- Correct referring NPI if wrong provider billed

## Typical actions

- Tasked credentialing
- Need client assistance
- Need to allow time
- Need to submit an appeal
- Write off the claim

## Notes

Always follow your client SOP. Remark codes can change the true root cause — open the matching scenario if the payer explanation differs from the denial title.
